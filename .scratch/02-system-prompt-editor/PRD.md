# PRD: 系统提示词编辑器（Prompt Override Editor）

Status: ready-for-agent

## 问题陈述

DSH 的系统提示词是多层动态组装的产物，用户无法在应用内查看或修改。当前修改方式是手动编辑 agent preset 的 `agent.cordis.yml` 文件，对普通用户不友好。不同模型（如千问）对系统提示词的身份声明有特定要求——千问模型的第一句话必须是"你是千问AI"才能激活特殊训练记忆，但 DSH 默认的身份段是 "You are an AI agent powered by DeepSeek Harness"，无法满足这类需求。用户还需要针对不同场景临时调整 AI 的人设描述，而不想每次都修改 preset 文件。

## 解决方案

提供一个系统提示词编辑器插件，通过覆盖层（overlay）机制在不修改 preset 原始文件的前提下，让用户编辑身份段和 persona 段的文本。采用三级作用域体系（全局 > 模型 > 会话），高优先级自动覆盖低优先级。双入口设计：设置面板管理全局和模型级配置，对话区 header 按钮快速编辑当前会话的临时覆盖。

## 用户故事

1. 作为用户，我想要在设置面板中编辑全局身份声明文本，以便所有会话都使用我自定义的身份声明
2. 作为用户，我想要为千问模型设置特定的身份声明（"你是千问AI"），以便使用该模型时自动激活特殊训练记忆
3. 作为用户，我想要为 DeepSeek 模型设置不同于千问的身份声明，以便每个模型都能获得最优的身份激活
4. 作为用户，我想要在设置面板中编辑全局人设描述文本，以便所有会话的 AI 都按照我定义的角色和风格回答
5. 作为用户，我想要在对话区的 session header 看到一个编辑按钮，点击后弹出当前会话的临时覆盖编辑器
6. 作为用户，我想要为当前会话临时设置一个不同的人设描述，以便在不影响其他会话的情况下试验不同风格
7. 作为用户，我想要为当前会话临时覆盖身份声明，以便在单个会话中测试不同的身份配置效果
8. 作为用户，我想要在编辑器中清楚看到身份声明和人设描述是两个分开的编辑区域，以便知道自己在改哪一层
9. 作为用户，我想要看到当前生效的覆盖来自哪个作用域（全局/模型/会话），以便理解配置的来源
10. 作为用户，我想要一键清除某个作用域的覆盖，恢复到默认值，以便在配置出错时快速回退
11. 作为用户，我想要在编辑器中看到当前 preset 的原始默认文本（作为参考），以便知道覆盖前的内容是什么
12. 作为用户，我想要编辑器中支持 `{{model}}`、`{{cwd}}` 等变量占位符，以便覆盖文本能感知运行时环境
13. 作为用户，我想要全局覆盖修改后立即对所有新发起的模型调用生效，以便不需要重启 DSH
14. 作为用户，我想要会话级覆盖仅影响当前会话，关闭或清除后其他会话不受影响
15. 作为用户，我想要模型级覆盖在我切换到对应模型时自动生效，切换走时自动失效，以便不需要手动开关
16. 作为用户，我想要设置面板中有一个模型选择器，让我为不同模型分别配置身份声明和人设描述
17. 作为用户，我想要编辑器的改动持久化保存，DSH 重启后覆盖配置仍然生效
18. 作为用户，我想要在编辑器中预览组装后的完整系统提示词（所有层合并后的最终文本），以便验证覆盖效果

## 实现决策

### 架构

1. **插件形态**：独立 Cordis 插件，同时有 host 半（注册 settings namespace + 监听 `system-prompt/assemble` 瀑布事件）和 client 半（UI 组件）。
2. **三级作用域覆盖体系（ADR-002）**：优先级从高到低为 会话级 > 模型级 > 全局级 > 原始 preset 默认值。高优先级覆盖低优先级的同名文本。详见 `docs/adr/ADR-002-three-level-scope.md`。
3. **存储**：通过 `ctx.settings` 注册 `prompt-overrides` namespace。Settings key 结构：`global.identity`、`global.persona`、`model:<modelName>.identity`、`model:<modelName>.persona`、`session:<sessionId>.identity`、`session:<sessionId>.persona`。
4. **集成 seam**：唯一的集成边界是 `system-prompt/assemble` 瀑布事件。插件在 host 侧监听该事件，读取 settings 中的覆盖配置，按三级优先级链替换 assembly 中的身份段和 persona 段文本。

### 编辑层级

5. **身份段（harness:identity）**：替换 order -100 的身份声明文本。当前默认值为 "You are an AI agent powered by DeepSeek Harness."。
6. **persona 段**：替换当前 agent preset 的 persona 人设描述文本。
7. **分开编辑**：身份声明和人设描述各自独立的文本编辑区域，分别标注清晰标签。

### UI

8. **设置面板入口**：通过 `settings.section` slot 注册一个完整的设置面板，包含：全局配置区（身份声明 + 人设描述）、模型配置区（模型选择器 + 该模型的身份声明 + 人设描述）、每个字段的"恢复默认"按钮、当前生效作用域的指示器。
9. **对话区入口**：通过 `conversation.session.header.actions` slot 在 session header 添加一个按钮，点击弹出会话级覆盖编辑弹窗（身份声明 + 人设描述 + 清除按钮）。
10. **原始文本参考**：编辑器中展示当前 preset 的原始默认文本（只读），供用户参考。
11. **预览功能**：提供"预览完整提示词"按钮，展示当前配置下组装后的完整系统提示词文本。

### 运行时行为

12. **即时生效**：覆盖配置修改后，下一次 `system-prompt/assemble` 调用时自动使用新值，无需重启。
13. **模型检测**：`system-prompt/assemble` 的 `AssembleContext` 中包含当前模型信息（`{{model}}` 变量在组装时解析），插件据此决定应用哪个模型级覆盖。
14. **持久化**：settings 系统自带持久化，覆盖配置跨 DSH 重启保留。
15. **变量支持**：覆盖文本支持 `{{model}}`、`{{cwd}}` 等变量占位符，在组装时由框架解析替换。

## 测试决策

### 测试策略

测试只验证外部行为：给定 settings 中的覆盖配置，验证 `system-prompt/assemble` 输出的最终提示词是否正确。不测实现细节。

### 测试模块

1. **三级优先级覆盖测试**：验证当同时存在全局、模型级、会话级覆盖时，最终提示词使用的是最高优先级的文本。逐一验证：会话级覆盖模型级、模型级覆盖全局级、全局级覆盖默认值。
2. **清除覆盖测试**：验证清除某个作用域的覆盖后，提示词回退到下一级优先级的文本。
3. **模型检测测试**：验证当模型为千问时使用千问的模型级覆盖，切换为 DeepSeek 时使用 DeepSeek 的模型级覆盖。
4. **身份段 + persona 段独立覆盖测试**：验证身份段覆盖不影响 persona 段，反之亦然。
5. **变量替换测试**：验证覆盖文本中的 `{{model}}` 和 `{{cwd}}` 在组装后被正确替换。
6. **持久化测试**：验证覆盖配置写入 settings 后可跨"重启"（模拟）恢复。

### 先例

`ui-agent-preset` 插件的 settings 集成模式可作为设置面板 UI 的参考。

## 超出范围

- **工具引导段编辑**：不编辑 per-preset 的工具引导段文本（这是基础设施层，由工具插件自行注册）。
- **追加自定义指令**：不提供在系统提示词末尾追加自由文本的功能（这属于 workspace instructions 范畴，通过 AGENTS.md 实现）。
- **workspace instructions 编辑**：不编辑 AGENTS.md / CLAUDE.md 文件。
- **多人协作同步**：覆盖配置仅存于本地 settings，不跨用户同步。
- **覆盖版本历史**：不记录覆盖文本的修改历史。
- **提示词模板市场**：不提供预设的覆盖模板供用户选择。

## 补充说明

- 本 PRD 的决策来源记录在 `docs/memorial/archived/002-system-prompt-editor/context.md`，包含 5 轮 grill 追问的完整对话记录。

- DSH 系统提示词在每次模型调用前重新组装（`SystemPrompt.assemble()`），因此覆盖修改即时生效，无需重启。
