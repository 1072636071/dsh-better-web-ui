# 对话区 session header 会话级覆盖

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 用户在对话区的 session header 中看到一个编辑按钮，点击后弹出会话级覆盖编辑弹窗。弹窗包含身份声明和人设描述两个编辑器，以及"清除覆盖"按钮。修改仅影响当前会话，不影响其他会话或全局/模型级配置。

**验收标准：**

- [ ] 通过 `conversation.session.header.actions` slot 在 session header 注册编辑按钮
- [ ] 点击按钮弹出会话级覆盖编辑弹窗
- [ ] 弹窗包含身份声明编辑器 + 人设描述编辑器
- [ ] 弹窗展示当前生效的值（可能来自会话级、模型级、全局级或默认值的覆盖链结果）
- [ ] "清除覆盖"按钮：清除当前会话级的覆盖，回退到下一级优先级
- [ ] 编辑后立即写入 settings（session:<sessionId> key），当前会话的下一次模型调用生效
- [ ] 关闭弹窗后其他会话不受影响
