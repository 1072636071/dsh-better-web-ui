# 持久化验证 + 变量替换验证

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 验证覆盖配置通过 settings 系统正确持久化，DSH 重启后覆盖仍然生效。验证覆盖文本中的 `{{model}}`、`{{cwd}}` 等变量占位符在系统提示词组装时被框架正确替换为实际运行时值。

**验收标准：**

- [ ] 覆盖配置写入 settings 后，DSH 重启后 settings 中仍可读取到配置
- [ ] 重启后的第一次系统提示词组装使用持久化的覆盖配置
- [ ] 覆盖文本中包含 `{{model}}` 时，组装后该占位符被替换为当前模型名
- [ ] 覆盖文本中包含 `{{cwd}}` 时，组装后该占位符被替换为当前工作目录
- [ ] 不存在的变量占位符保持原样（不报错、不崩溃）
- [ ] settings 数据损坏时优雅降级（清除损坏数据，回退到默认值）
