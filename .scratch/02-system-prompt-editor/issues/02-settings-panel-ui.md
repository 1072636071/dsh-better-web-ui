# 设置面板 UI（全局 + 模型级配置）

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 用户在 DSH 设置面板中看到"提示词覆盖"区域，可以编辑全局身份声明和人设描述，也可以通过模型选择器为特定模型（如千问、DeepSeek）配置独立的身份声明和人设描述。每个字段有"恢复默认"按钮，并有指示器显示当前生效的覆盖来源。

**验收标准：**

- [ ] 通过 `settings.section` slot 注册"提示词覆盖"设置面板
- [ ] 全局配置区：身份声明文本编辑器 + 人设描述文本编辑器
- [ ] 模型配置区：模型选择器（列出可用模型），选中后展示该模型的身份声明 + 人设描述编辑器
- [ ] 每个字段有"恢复默认"按钮，点击后清除该字段的覆盖
- [ ] 当前生效作用域指示器：显示每个字段当前使用的是全局覆盖、模型覆盖还是默认值
- [ ] 编辑器中展示当前 preset 的原始默认文本（只读参考）
- [ ] 编辑后立即写入 settings，下一次模型调用生效
