# PRD: 会话抽屉（Session Drawer）

Status: ready-for-agent

## 问题陈述

DSH 对话区一次只能展示一个会话。当用户在多个工作目录和多个会话之间频繁切换时，每次切换都需要回到侧边栏重新导航，丢失了已打开会话的上下文。用户需要一个快速切换上下文的方式，同时不占用对话区的宝贵垂直空间。

## 解决方案

在对话区添加一个可从顶部滑出的抽屉面板（Session Drawer），专门用于管理多会话/多工作目录的切换。抽屉通过 shell.overlay（已有的浮动层 slot）实现，纯插件，不修改核心包。

抽屉收起时对话区零额外开销，全屏展示当前会话。打开抽屉后展示两层结构：工作目录列表 + 该目录下的会话列表。点击会话关闭抽屉并切换到该会话。支持从侧边栏拖拽会话/工作目录到抽屉内创建条目。

## 用户故事

1. 作为多项目开发者，我想要通过一个快捷键或按钮打开会话管理抽屉，以便快速查看和切换已打开的多个会话
2. 作为用户，我想要从侧边栏拖拽一个会话到抽屉面板中，以便将该会话添加为可快速切换的条目
3. 作为用户，我想要从侧边栏拖拽一个工作目录到抽屉面板中，以便将该目录下的所有会话纳入管理
4. 作为用户，我想要在抽屉中点击一个会话条目，以便关闭抽屉并切换到该会话的对话内容
5. 作为用户，我想要在抽屉中按工作目录分组查看已添加的会话，以便在多个项目上下文间快速定位
6. 作为用户，我想要点击遮罩层或按 Esc 关闭抽屉，以便回到专注工作模式
7. 作为用户，我想要使用键盘快捷键（如 Ctrl+Shift+T）打开/关闭抽屉，以便无需鼠标即可快速切换
8. 作为用户，我想要 hover 一个条目时看到关闭按钮（×），点击即可从抽屉中移除该条目
9. 作为用户，我想要在抽屉内拖拽条目调整顺序，以便按照自己的习惯排列
10. 作为用户，我想要页面刷新或 DSH 重启后抽屉中的条目仍然保留，以便不需要重新添加
11. 作为用户，我想要关闭一个工作目录条目时同时移除其下所有会话条目，以便一次性清理
12. 作为用户，我想要拖拽一个已存在的会话到抽屉时不创建重复条目，而是高亮已有条目
13. 作为用户，我想要抽屉面板有搜索/筛选功能，以便在条目较多时快速找到目标会话
14. 作为用户，我想要抽屉打开时有平滑的滑入动画，关闭时有滑出动画，以便体验流畅

## 实现决策

### 架构

1. **纯插件实现**：通过 `shell.overlay`（已有的 list/root scope slot）注册抽屉组件。不修改任何核心包代码。
2. **多会话打开模型**：插件 store 独立维护"已添加会话"列表，与现有 `SessionListState.current`（单当前会话）并存。点击条目时调用 `SessionRuntime.open(sessionId)` 让该会话成为全局当前会话。
3. **插件形态**：独立 Cordis 客户端插件，host 半为空，client 半注册 shell.overlay 入口和 store。

### 交互

4. **打开/关闭抽屉**：触发按钮（对话区右上角小图标）+ 键盘快捷键 `Ctrl+Shift+T`。打开时从顶部滑出面板（约 40-50% 视口高度），带半透明背景遮罩。关闭方式：点击遮罩、按 Esc、点击条目后自动关闭。
5. **从侧边栏拖入**：拖 session 到抽屉添加为会话条目；拖 workspace header 到抽屉添加为该 workspace 分组。去重：已存在的条目不重复添加，改为高亮闪烁提示。
6. **× 按钮移除**：hover 条目时显示关闭按钮，点击移除。关闭 workspace 条目级联移除其下所有 session 条目。
7. **条目拖拽重排序**：支持在抽屉内拖拽调整条目顺序。
8. **搜索/筛选**：抽屉顶部一个搜索框，输入时实时筛选条目（匹配会话标题和工作目录名称）。

### 状态管理

9. **持久化**：使用框架 `defineStore({ persist: 'dsh.drawer' })` 管理抽屉状态。Session ID 和 Workspace ID 均为稳定 UUID，跨刷新和重启均恢复。
10. **两层结构**：抽屉内按 workspace 分组展示 session 条目。每个 workspace 分组可独立折叠/展开。

### 渲染

11. **抽屉面板**：通过 shell.overlay 渲染为全视口浮动层。面板从顶部滑出，宽度居中（约 600px 或 60% 视口宽度取较小值），高度约 40-50% 视口高度。半透明遮罩覆盖其余区域。
12. **收起态**：不渲染任何可见 UI（触发按钮除外）。触发按钮是一个小的固定定位图标按钮，位于对话区右上角。
13. **无条目时**：抽屉内显示空状态提示（"从侧边栏拖拽会话或工作目录到这里"）。

## 测试决策

### 测试策略

测试只验证外部行为（store 状态 → 组件渲染结果），不测实现细节。seam 收敛在 shell.overlay 注册 + store 状态这一层。

### 测试模块

1. **Drawer Store 单元测试**：添加/移除条目、去重、级联移除、重排序、搜索筛选、持久化读写。
2. **Drawer 组件渲染测试**：打开/关闭状态、条目列表渲染、空状态、搜索筛选交互。
3. **拖拽交互测试**：从侧边栏拖入、去重高亮、无效 drop 处理。
4. **键盘交互测试**：快捷键打开/关闭、Esc 关闭。

### 先例

侧边栏 workspace browser 的拖拽测试可作为拖拽交互测试的参考。

## 超出范围

- **跨窗口/跨标签页共享抽屉状态**：状态仅在当前浏览器标签页内有效。
- **条目分组/着色**：不支持自定义分组或着色（按 workspace 自动分组）。
- **条目拖出独立窗口**：不支持将条目拖出抽屉形成独立窗口。
- **跨工作目录移动条目**：不支持将 session 条目从一个 workspace 分组拖到另一个。
- **移动端/触控优化**：拖拽交互优先桌面端。
- **会话预览**：hover 条目时不展示会话内容的预览或缩略图。
