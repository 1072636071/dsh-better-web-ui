# 搜索筛选

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 抽屉顶部有一个搜索框，用户输入时实时筛选条目——匹配会话标题和工作目录名称。搜索为空时显示全部条目。

**验收标准：**

- [ ] 抽屉顶部渲染搜索输入框
- [ ] 输入时实时过滤 session 条目（匹配标题，大小写不敏感）
- [ ] workspace 分组在其下所有 session 均不匹配时隐藏
- [ ] 搜索框清空后恢复显示全部条目
- [ ] 搜索状态不持久化（关闭抽屉后清空搜索词）
