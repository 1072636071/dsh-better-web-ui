# ADR-002: 系统提示词编辑器的三级作用域

## 状态

已决策 (2026-08-21)

## 背景

DSH 系统提示词是多层动态组装的产物。用户需要在不修改 preset 原始文件的前提下，灵活覆盖身份段和 persona 段的文本。不同模型（如千问）对身份段有特定的激活要求，不同会话可能需要临时人设调整。

## 决策

采用**三级作用域覆盖体系**，优先级从高到低：

1. **会话级（session）** — 单个会话的临时覆盖，仅影响当前会话
2. **模型级（model）** — 针对特定模型（如 qwen-max）的覆盖，使用该模型的所有会话自动应用
3. **全局级（global）** — 影响所有会话，无论 preset 和模型
4. 原始 preset 默认值（最低优先级）

存储通过 `ctx.settings` 的 `prompt-overrides` namespace 实现。组装时通过 `system-prompt/assemble` 瀑布事件，按优先级链解析覆盖层文本替换原始身份段/persona 段。

## 被否决的替代方案

1. **仅全局覆盖**：最简单，但无法满足千问模型的特定身份需求，也无法做会话级临时调整
2. **按 preset 分别配置**：粒度不够细（不区分模型），且管理成本高
3. **全局身份段 + 按 preset 的 persona**：不满足会话级临时覆盖需求

## 后果

- **正面**：灵活度最高，一个千问身份声明覆盖所有会话，同时允许单个会话临时修改人设
- **负面**：三级优先级链增加了调试复杂度（用户可能不清楚当前生效的是哪一层）
- **缓解**：编辑器 UI 中明确显示当前生效的作用域来源和覆盖链路
