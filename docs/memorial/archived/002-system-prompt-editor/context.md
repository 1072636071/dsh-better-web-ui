# 002 · 系统提示词编辑器

## 诉求

> 我还想做一个入口，可以修改会话的系统提示词，可以灵活的修改

## 追问记录

### Q1 · 想修改系统提示词的哪一层？ [2026-08-21]

**调研事实**：DSH 系统提示词是多层动态组装：全局身份段(harness:identity, order -100) + persona段(order 0) + 工具引导段(per-preset) + 变量替换 + 运行时上下文。当前身份段内容为纯静态字符串 "You are an AI agent powered by DeepSeek Harness."。

**提问**：想改哪一层？身份段、persona段、追加自定义指令、还是完整覆盖？

**用户回答**：身份段也要改。原因：千问模型的第一句话必须是"你是千问AI"才能激活特殊的训练记忆。

**分析**：这改变了"身份段不需要编辑"的假设。不同模型有不同的身份激活需求，身份段编辑有真实的实用价值。编辑器需要覆盖至少身份段 + persona 段两层。

### Q2 · 编辑的作用域层级 [2026-08-21]

**提问**：全局生效、按 preset 分别配置、还是全局身份段 + 按 preset 的 persona？

**用户回答**：三种都要——**全局的、会话级别的、针对某个模型的**。

**分析**：用户需要一个三级作用域体系：
- **全局**：改一次，所有 preset/模型/会话都生效
- **按模型**：针对特定模型（如千问）的身份声明，使用该模型时自动应用
- **按会话**：单个会话的临时覆盖，不影响其他会话

优先级链（高到低）：会话级 > 模型级 > 全局级 > 原始 preset 默认值。

### Q3 · 编辑粒度：分开还是合并 [2026-08-21]

**提问**：身份段和 persona 段在编辑器里分开编辑还是合并？

**用户回答**：**分开编辑** — 两个独立文本区域，分别标注「身份声明」和「人设描述」。

### Q4 · 存储方式 [2026-08-21]

**提问**：编辑内容存在哪里？Settings 覆盖层、独立文件、还是直接改 preset YAML？

**用户回答**：**Settings namespace 覆盖层** — 通过 `ctx.settings` 注册新 namespace（如 `prompt-overrides`），组装时通过 `system-prompt/assemble` 瀑布事件替换原始文本。三级作用域对应三个 key（`global`、`model:<name>`、`session:<id>`）。

### Q5 · 编辑器入口位置 [2026-08-21]

**提问**：编辑器入口放在设置面板、对话区、还是两者都有？

**用户回答**：**双入口** — 设置面板放完整编辑器（全局 + 按模型配置），对话区 session header 加按钮弹出会话级临时覆盖编辑。
